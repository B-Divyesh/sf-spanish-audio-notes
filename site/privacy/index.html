Legal / privacidad

Cómo tratamos tus datos

Vigente desde el 6 de septiembre de 2026.

Datos en la aplicación

Audio Margin procesa grabaciones, transcripciones, marcas, preguntas y preferencias en tu dispositivo. No recibimos ni alojamos esos datos. Puedes borrar cada sesión desde la aplicación.

Modelos y red

La aplicación usa internet para descargar el modelo elegido y verificar una licencia como máximo una vez al día. La transcripción no se envía por red.

Compra

Sociobot y Dodo actúan como comerciante registrado. Procesan los datos necesarios para pagos, recibos y reembolsos. Audio Margin guarda el token de licencia y su verificación en tu dispositivo.

Sitio web

Este sitio no usa cookies publicitarias, píxeles ni scripts de análisis de terceros. Consulta la API de GitHub para mostrar el instalador disponible. El alojamiento puede conservar registros técnicos breves para seguridad.

Contacto

Para consultas, escribe a privacy@sociobot.in.
