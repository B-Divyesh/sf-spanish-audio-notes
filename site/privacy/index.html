Datos en la aplicación

Audio Margin procesa grabaciones, transcripciones, marcas, preguntas y preferencias exclusivamente en tu dispositivo. No recibimos ni alojamos esos datos. Puedes borrar una sesión desde la aplicación o eliminar todos los datos desinstalándola y borrando su carpeta local.

Modelos y red

La aplicación usa internet solo para descargar el modelo de transcripción que elijas, comprobar actualizaciones cuando tú lo solicites y verificar una licencia como máximo una vez al día. La transcripción no se envía por red.

Compra

Sociobot y Dodo actúan como comerciante registrado y procesan los datos necesarios para pago, recibos y reembolsos bajo sus propias políticas. Audio Margin guarda el token de licencia en tu dispositivo.

Sitio web

Este sitio no usa cookies publicitarias, píxeles ni scripts de análisis de terceros. El alojamiento puede conservar registros técnicos breves para seguridad y fiabilidad.

Contacto

Para consultas, escribe a privacy@sociobot.in.
